<p align="left">在 iOS 27.0 beta 1 - 4 系统上修改 MobileGestalt 配置文件的工具！</p>

> [!NOTE]  
> 本项目为开源项目 [rooootdev/mond](https://github.com/rooootdev/mond) 的简体中文汉化与本地化构建版本。原项目版权归原作者 [rooootdev](https://github.com/rooootdev) 所有。

> [!WARNING]  
> 部分修改选项有导致设备变砖（白苹果/无限重启循环）的风险！请自行承担使用风险。

**计划开发功能：**<br>
&#45; HouseArrest 文件浏览器 (iOS 18 - 27?)

**已知问题：**<br>
&#45; 重启设备后部分修改可能会失效或消失<br>
&#45; Apple Intelligence（Apple 智能）激活功能目前不可用<br>
&#45; “禁用地区功能限制”在某些 iOS 版本或特定设备上可能会失效<br>
&#45; iPadOS UI 及相关修改可能无法正常工作，并且有可能导致设备进入**无限重启 (Bootloop)** 状态！
